# Design system in use (read before touching any component)

The site is a calling card: something to send to a recruiter that reads in under
a minute. Light theme, one typographic voice, one shape repeated. Nothing here is
optional.

## Colour: five tokens, light only

Defined in `app/globals.css` as HSL triplets, exposed to Tailwind in
`tailwind.config.js` as `bg`, `surface`, `ink`, `ref`, `rail`, `accent`.

| token | role | Tailwind |
| --- | --- | --- |
| `--bg` | page, white | `bg-bg` |
| `--surface` | code blocks, chart frames, demo panels | `bg-surface` |
| `--ink` | primary text, results, chart bars | `text-ink`, `bg-ink` |
| `--ref` | metadata, summaries, labels, axes | `text-ref` |
| `--rail` | hairlines only, never information | `border-rail` |
| `--accent` | focus ring, hover underline, failure states | `text-accent`, `bg-accent` |

Hard rules:

- **No Tailwind palette colours** (`gray-*`, `blue-*`, …) and no hex literals.
  Every colour comes from the tokens.
- **There is no dark mode.** No `dark:` variants, no theme provider, no toggle.
  A colour-scheme switch is a control nobody asked for on a page this short.
- `--accent` is not decoration. It marks a failure branch, the focus ring, and
  the hover state of a link. Nothing else.
- `--rail` never carries information a reader must see.
- Need a subtle fill? `bg-ink/[0.05]`. A subtle hover? `hover:bg-ink/[0.02]`.

## Type: two families, one rule

- `font-mono` (Chivo Mono, self-hosted) for anything that is a label, an
  identifier, a number, a heading, a nav item, a chart tick, or code.
- default sans (Geist) for sentences.
- Sizes come from the scale in `tailwind.config.js`. Do not invent sizes with
  arbitrary values unless a clamp is genuinely needed.
- Weights available: 400, 500, 600.

## Structure: one row, repeated

`components/row.tsx` is the whole site. Title plus meta on one line, one line of
summary, then the written result and the links you can open. Projects, roles,
degrees and awards all use it, so there is one shape to learn.

- Rows are separated by a hairline. Sections are announced by `SectionHeader`.
  Those are the only two structural levels.
- **No cards.** No bordered boxes around content, no shadows, no gradients.
- Radius is 3px everywhere.
- No bars or charts in the lists. A result is a sentence with the number in it:
  "1,194 GB/s effective, above the 900 GB/s HBM peak". Charts belong on the
  detail pages, where there is room to read them.

## Artifacts come first

Every entry carries `links: {label, href}[]` for what a reader can open: source,
package, live demo, paper, book. They are rendered on the row, in the detail page
header, and again in the detail page footer. If something exists in public it
gets a link; a page that mentions work without linking to it is doing half a job.

## Motion

Nothing animates on entry. Hover transitions are colour only, 150ms.
`prefers-reduced-motion` is respected globally in `app/globals.css`.

## Recharts

Recharts writes `fill` and `stroke` as SVG presentation attributes, where
`var()` is not reliable. Use the classes defined in `app/globals.css`:
`chart-ink`, `chart-ref`, `chart-accent` (fills) and `chart-ink-stroke`,
`chart-ref-stroke`, `chart-accent-stroke`, `chart-rail-stroke` (strokes), via the
`className` prop. For `Tooltip`, `contentStyle` is an inline style and takes
`hsl(var(--surface))` directly.

## Assets under a base path

The production site lives at `/alepot55` on GitHub Pages and at the root
everywhere else. Any asset the client requests itself (the chess piece SVGs) must
use `process.env.NEXT_PUBLIC_BASE_PATH`, which `next.config.mjs` sets to exactly
the prefix the build used. Never hardcode `/alepot55`: that bug hid the chess
pieces on every deployment that was not GitHub Pages.

## Accessibility floor

- Nothing below 11px.
- Interactive targets at least 44px in both dimensions, padding counts.
- Keyboard focus is handled globally by `*:focus-visible`; do not override it.
- Anything purely decorative gets `aria-hidden="true"`.

## Writing

No em dashes, no emoji, no glyphs outside Latin-1. Sentence case for prose,
lowercase for nav. Units spelled as they read ("GB/s", not "GB/S").
